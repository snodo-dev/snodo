## INTENT
A protocol author can list, per LLM-type validator, which plugin-provided tools that validator may use, with optional per-tool options. Validators that list nothing behave, compile and serialise exactly as today.

## THE CHAIN
- A sibling task added a registry for plugin-provided validator tools (entry-point group `snodo.validator_tools`). A later task wires it into the LLM validator.
- Validator configuration is modelled in `packages/snodo-foundation/src/snodo/compiler/models.py` and published in `schemas/protocol-v1.json`, which `tests/scripts/test_protocol_schema_publication.py` pins.
- The template golden snapshots (`tests/golden/test_template_snapshots.py`, snapshots under `tests/golden/snapshots/`) pin each shipped template's compiled form.

## CONSTRAINTS
