## INTENT
A reader of the model docs learns that snodo cloud is a built-in model provider, and how to use it. The docs cover:
- log in to snodo cloud (`snodo cloud login`, or `snodo cloud connect` with an API key);
- name models `snodo-cloud/<id>`, for example "snodo-cloud/gpt-6-luna" or "snodo-cloud/@cf/qwen/qwen3.8-27b";
- list the organisation's enabled models with `snodo models --provider snodo-cloud`;
- use it for the coder with `opencode-cli/snodo-cloud/<id>`;
- billing follows the organisation's setting in snodo cloud (Models → Billing), with one monthly limit;
- the gateway URL defaults to https://models.snodo.dev/v1 and can be changed with `cloud.models_url`.
