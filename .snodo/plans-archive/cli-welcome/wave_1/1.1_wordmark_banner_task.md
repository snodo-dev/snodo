# The CLI has no wordmark

First open a GitHub issue for this work. Write the body to a file under /tmp and pass it with `gh issue create --body-file`, never as an inline string. The commit message must say "Fixes #<that issue number>". Add a CHANGELOG entry under ## [Unreleased].

## INTENT
snodo gets a small, reusable wordmark that matches the snodo.dev logo. Bare `snodo`, top-level `--help` and the installer can then share it. This task only builds the renderer; a later task wires it in.

## THE CHAIN
- Today bare `snodo` prints a plain "Start here" list (`snodo/cli/main.py`, `_app_callback`). Nothing in the CLI carries the brand.
- The maintainer approved this exact design: three rows of thin box-drawing letters reading "snodo.dev", followed by the version. Rows, exactly (the "▪" is the dot):
```
╭──  ┌─╮  ╭─╮  ╭─┤  ╭─╮   ╭─┤  ╭─╮  ╷   ╷
╰─╮  │ │  │ │  │ │  │ │   │ │  ├─╯  ╰╮ ╭╯
──╯  ╵ ╵  ╰─╯  ╰─╯  ╰─╯ ▪ ╰─╯  ╰──   ╰─╯  0.24.0
```
- Colours, as 24-bit ANSI:
  - "snodo" in light grey #dce3e6;
  - "▪" and "dev" in teal #2ccfbc;
  - the version in slate #647f8f.
- The version on the last row comes from `snodo.version.__version__`.
- The existing spinner (`snodo/cli/spinner.py`) already has a TTY and `NO_COLOR` decision. Reuse or follow it.

## CONSTRAINTS
- Put it in a new small module, for example `banner.py` in the `snodo.cli` package. It should offer:
  - a function returning the plain-text wordmark (no escape codes);
  - a function returning the coloured one;
  - a helper that decides whether to show it at all, true only when the target stream is a TTY.
- Colour is dropped when `NO_COLOR` is set. Follow the existing check.
- No trailing spaces on any row. No blank line above or below the three rows. The glyphs must stay exactly as above.
- Don't wire it into any command yet.
- Never pass text containing backticks or `$(` through an inline shell string. Commit messages and issue bodies go through files under /tmp.
- Do not run the `snodo` CLI against this repo, `make release` or `make gate` in the worktree, and do not create, change or delete anything under `.snodo/` in the repo.
- Run `uv run ruff check` and `uv run python scripts/enforce_file_length.py` on touched files. Run only the new banner tests.

## ACCEPTANCE
- Tests show:
  - the plain wordmark matches the three rows above, with the current version on row three;
  - the coloured form, stripped of escape codes, equals the plain form;
  - `NO_COLOR` yields no escape codes;
  - the show-helper is false for a non-TTY stream.
- There is a CHANGELOG entry under ## [Unreleased].
