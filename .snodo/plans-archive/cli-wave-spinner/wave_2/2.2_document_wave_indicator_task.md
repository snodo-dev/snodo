INTENT
The CLI now has a "wave" loading indicator for slow, silent commands. Operators and integrators need to know:
- what it looks like;
- that it only ever writes to stderr, so stdout and `--json` are unaffected;
- when it appears: interactive terminal only, after a short delay;
- when it is automatically off: CI, NO_COLOR, TERM=dumb, the MCP server and background jobs;
- how to force it off: the opt-out env var the wave 1 component implemented. Read the code to get its exact name; don't guess.

When this is done, the docs answer these questions where readers already look: the command reference and/or configuration docs, plus a line in docs/machine-interface.md confirming that stdout and JSON stay clean. Keep it short. One example line of the indicator, a sentence on behaviour, and the opt-out are enough.
