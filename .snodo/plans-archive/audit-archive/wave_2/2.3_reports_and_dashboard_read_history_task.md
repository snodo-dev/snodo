# Task reports, hand-completion lookups and the dashboard still see archived history

First open a GitHub issue for this work. Write the body to a file under /tmp and pass it with `gh issue create --body-file`, never as an inline string. The commit message must say "Fixes #<that issue number>". Add a CHANGELOG entry under ## [Unreleased].

## INTENT
Several commands read the full audit history from the events the audit log loaded into memory:
- `snodo task report` and the pending-review list;
- the lookup of hand-completion records;
- the list of task branches;
- the models baseline that finds merge events;
- the dashboard's per-session event view.

Once the log is archived weekly or by size, opening it loads only the current file, so these would quietly lose anything older than the current archive window. They should read through the archive-aware history walk added earlier in this plan, streamed oldest first, so a report over the last month still counts last month's work.

## THE CHAIN
- `snodo/cli/commands/task_cmd.py`: report, pending review and task branches.
- `snodo/cli/commands/task_complete.py`: the hand-completion record.
- `snodo/cli/commands/models_baseline.py`: merge events.
- `snodo/dashboard/providers.py`: per-session events. Its bounded tail view of recent events is fine as it is.
- The history walk in `packages/snodo-foundation/src/snodo/infrastructure/audit.py`, from task 1.1. This task may build on task 1.1's branch.

## CONSTRAINTS
- With no archives, output is identical to today.
- Stream the history. Do not concatenate everything into memory.
- No new audit event, status, severity or halt type.
- Do not run the `snodo` CLI against this repo, `make release` or `make gate` in the worktree, and do not create, change or delete anything under `.snodo/` in the repo.
- Run `uv run --extra dev ruff check` on touched files, and run the task command, models and dashboard tests.

## ACCEPTANCE
- Tests show, with synthetic archives:
  - the task report counts work recorded only in an archive;
  - pending review and hand-completion lookups find archived records;
  - the dashboard session view includes archived events for that session;
  - with no archives, output is unchanged.
- There is a CHANGELOG entry under ## [Unreleased].
