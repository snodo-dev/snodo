# Bare `snodo` shows the wave while it gathers the status view

First open a GitHub issue for this work. Write the body to a file under /tmp and pass it with `gh issue create --body-file`, never as an inline string. The commit message must say "Fixes #<that issue number>". Add a CHANGELOG entry under ## [Unreleased].

## INTENT
Bare `snodo` prints the wordmark, then pauses noticeably before the status lines (protocol, coder, cloud, readiness, next step). During the pause the user sees nothing. It is slowest when the readiness check and the cloud sync notice are being worked out. The snodo wave should show during that pause and clear the moment the status view prints. The opt-in helper made for `snodo cloud status` does exactly this for a silent phase after the first output.

## THE CHAIN
- `snodo/cli/main.py`, the bare-`snodo` branch: prints `colored_wordmark()`, then `print(render_home_view(color=is_tty), end="")`.
- `snodo/cli/home_view.py`, `render_home_view`: loads the protocol, runs `assess_readiness`, and calls `sync_issue_notice()`. That is the pause.
- `snodo/cli/spinner.py`: `wave_while_silent(label)`, already used for the later silent phase in `snodo/cli/commands/cloud_cmd.py` ("reading sync state").
- An earlier task in this plan changed the same `main.py` branch area for `--version`; build on it.

## CONSTRAINTS
- Reuse the existing helper and its TTY rules. Non-TTY and NO_COLOR output stays byte-identical to today.
- The wave never stays on screen or interleaves with the printed view, including when rendering raises.
- Use a short, soft label, for example "checking the project".
- No new status, severity, halt type or audit event.
- Do not run the `snodo` CLI against this repo, `make release` or `make gate` in the worktree, and do not create, change or delete anything under `.snodo/` in the repo.
- Run `uv run --extra dev ruff check` on touched files, and run the home view, spinner and main CLI tests.

  - without a TTY, output is unchanged and has no escape codes;
  - an exception during rendering leaves no wave on screen.
