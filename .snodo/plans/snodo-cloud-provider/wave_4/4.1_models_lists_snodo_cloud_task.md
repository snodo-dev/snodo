# `snodo models --provider snodo-cloud` says the provider is not configured

This work is tracked by GitHub issue #871, which is already open; reference it as "Fixes #871" and keep exactly one CHANGELOG entry for #871 under ## [Unreleased].

## INTENT
When the user is logged in to snodo cloud, `snodo models` counts snodo-cloud as a configured provider, and `snodo models --provider snodo-cloud` lists the organisation's enabled models from the gateway's `GET /v1/models` as "snodo-cloud/<id>". Without a login, the provider is listed as unavailable, with a hint to run `snodo cloud login`. The change lands with the whole gate green.
