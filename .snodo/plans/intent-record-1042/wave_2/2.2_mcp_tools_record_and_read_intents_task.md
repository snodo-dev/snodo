## Intent
An orchestrator working through MCP needs to record an intent before cutting plans from it, and to read intents back. This task exposes the intent store (the `intent_store` module in packages/snodo-foundation/src/snodo/infrastructure/, from task 1.1) as MCP tools. It does not connect plans to intents.
