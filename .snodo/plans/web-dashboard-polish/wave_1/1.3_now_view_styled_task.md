New files this task will create: `snodo/web/static/now.css`, `tests/web/test_static_now_style.py`.

INTENT
The Now view has no styling. Evidence from a running dashboard: the four counts run together on one line as plain text ("1 projects with work in flight2 plans in flight..."), and the in-flight tree and the waiting items show as raw nested bullet lists. snodo/web/static/now.js emits the counts as unclassed spans and gives most list items no class at all.

What the person should see: a row of count tiles, each a large number over a small label; each project as a card, with its plans nested and its tasks as tidy rows showing the task id, a coloured status chip, and the job id with elapsed time in a monospace face; idle projects visibly quieter; the "Waiting on you" entries as cards with a coloured edge so a plan not merged into main and uncommitted files look different; empty states as a quiet line. It should reflow on a phone width and read well in light and dark themes.

Indications: give the elements the script builds meaningful classes (count, project, plan, task, status chip per task status, waiting entry per kind, empty), split each count into number and label, and write now.css using only the colour tokens already defined in the page, tinting with color-mix. The page shell (another task) loads now.css when it loads now.js and supplies shared heading and table styling; do not restyle those here.
