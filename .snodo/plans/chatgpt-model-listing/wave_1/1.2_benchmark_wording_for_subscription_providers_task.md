## Intent
Benchmarking a model on a ChatGPT subscription provider tells the truth about cost: those calls use the subscription and are not billed per API call.

## Evidence
- `snodo models --benchmark chatgpt/gpt-6.1-sol` prints "This makes 3 real, billed API call(s)." although the provider signs in with a ChatGPT subscription (setting `auth: chatgpt-oauth`) and Snodo does not price it. The sentence is printed by the benchmark confirmation in the models command module, and the option help for `--benchmark` also says "Makes real, billed API calls."
- The same run prints several LiteLLM "Pydantic serializer warnings" about the ChatGPT backend's usage block (output_tokens is 0 there). They are noise for the operator; suppress them for the benchmark call only if that can be done without hiding other warnings, otherwise leave them.
- The config manager has a helper `provider_uses_oauth(provider)` for telling these providers apart.

## Outcome
- For a model whose provider uses OAuth, the benchmark confirmation says the calls use the operator's subscription, with the same number of runs; for other providers the sentence is unchanged.
- The `--benchmark` option help no longer claims every call is billed; it says calls may be billed or use a subscription.
- Tests cover the OAuth wording, the unchanged API-key wording and the help text.
- `make gate` passes, including ruff, import-linter and the file-length and docs-coverage checks.
