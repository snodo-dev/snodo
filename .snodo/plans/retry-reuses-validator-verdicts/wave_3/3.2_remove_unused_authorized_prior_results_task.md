## INTENT
Task 1.2 of this plan added a pure lookup for authorized prior validator warns, `packages/snodo-engine/src/snodo/engine/authorized_prior_results.py`, with six tests in `tests/engine/test_authorized_prior_results.py`. It was meant to let a retry skip dispatching an authorized validator. That design was dropped: the verdict cache already answers a retry for any cached verdict on an identical subject (task 2.1 of this plan, delivered), and the signed decision is applied afterwards by the policy. The helper was never wired into anything, so it is dead code with tests that pin it, and its CHANGELOG line promised a capability the product does not have.
