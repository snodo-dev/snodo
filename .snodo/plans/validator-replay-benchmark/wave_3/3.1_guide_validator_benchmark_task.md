# 3.1_guide_validator_benchmark

## INTENT
The user guide `docs/choosing-models.md` has a walkthrough for benchmarking a coder on a baselined task. This plan added the same for one validator: replay it on the recorded spec and tree with another model and compare the verdict, time and tokens. A reader needs to find that path, know that it judges the recorded commit and not the current checkout, and know how to read the result.

## STARTING STATE
Waves 1 and 2 are merged: `snodo models --benchmark-run --plan <plan> --task <task> --validator <id> --model <provider/model>` works and is tested in `tests/cli/test_models_benchmark_run_validator.py`. The walkthrough for the coder benchmark in `docs/choosing-models.md` was added by plan benchmark-docs-and-archived-plans; if it is not in the file, write the new section so that it stands alone and say so in the final message.
