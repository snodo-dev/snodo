INTENT
On first landing the Now page should use its full width for the tree; the task panel appears only when a task is selected, and closing it gives the width back.

Evidence: after the redesign the right-hand panel is on screen from the start but empty ("pick a task" state), so a third of the page is unused until the visitor clicks. Ylli prefers the page to start at full width and make room on selection.

What it should do: with nothing selected the tree takes the whole content width and no panel, placeholder or empty column is rendered. Selecting a task row (or the attention strip's Show task button) opens the panel and the layout becomes tree plus panel, the tree narrowing to make room. The panel's Close button and the Escape key close it, clear the selected-row mark and return the tree to full width, and focus goes back to the row that opened it. A selection still survives the ten-second refresh; if the selected task disappears the panel closes and the width returns. Narrow screens keep the existing stacked behaviour. A short width transition is fine and is switched off for visitors who prefer reduced motion.
