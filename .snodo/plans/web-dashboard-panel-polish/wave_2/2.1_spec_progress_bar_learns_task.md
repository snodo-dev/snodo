INTENT
While a task's spec is loading, the panel should show a progress bar that gives an honest sense of how long it will take and learns from earlier loads, instead of a single "loading" word.

Evidence: snodo/web/static/now.js shows the text "Loading spec…" for the whole time the spec request is pending, which can be several seconds; the visitor has no idea whether it is nearly done.

What it should do: while a spec request is pending the panel body shows a slim progress bar with a short caption. The bar fills smoothly toward about nine tenths of its length over an expected duration and never claims completion before the answer arrives; when the answer arrives the bar completes quickly and gives way to the rendered spec. The expected duration starts at ten seconds when nothing is known. Each finished load records how long it took; the page keeps the most recent ten durations and uses their average as the next expected duration, so the bar tracks how this machine actually behaves. The durations are kept in the browser's local storage when available and in memory otherwise, and every read and write tolerates storage being missing or blocked. If a load runs past the expected duration the bar keeps creeping very slowly and the caption changes to say it is taking longer than usual. Failures and the "no spec" answer end the bar the same way and keep their existing messages and retry. For visitors who prefer reduced motion the bar does not animate and the caption carries the elapsed seconds instead. The bar is exposed to assistive technology as a progress indicator with a text alternative.

Tests that exist and pass: a pending spec request renders the bar with the caption; the first expected duration is ten seconds; after recorded loads the expected duration is the average of the last ten; storage failures fall back to memory without throwing; the bar completes and is replaced by the spec on success, and ends on failure and on a missing spec with the existing messages; the slow-load caption appears after the expected duration; the reduced-motion rule and the progress semantics exist; no innerHTML, external host or hex colour appears; the existing now tests still pass. `make gate-task` is green.
