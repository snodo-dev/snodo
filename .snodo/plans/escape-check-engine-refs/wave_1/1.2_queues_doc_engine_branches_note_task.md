Evidence: docs/queues.md currently carries this paragraph: "Plans in different queues can run at the same time without tripping each other's workspace-escape check: branches belonging to other plans are ignored. An earlier attempt at this ticket ended with the coder writing nothing, so the change needs to be made explicitly. The new text must no longer say the task's own plan branches count as an escape. Plain and short. Then add the changelog entry.
