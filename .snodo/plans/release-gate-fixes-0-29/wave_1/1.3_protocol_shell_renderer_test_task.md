INTENT
The protocol shell test checks that each Protocol section script registers its renderer, without demanding a placeholder call that one script never made.

Evidence: the full gate fails tests/web/test_static_protocol_shell.py::test_protocol_section_scripts_register_in_shell_order. After confirming the script tags appear in the page in the order tiles, pipeline, validators, execution, savebar, it requires the exact text registerRenderer(() => {}) in each of the five scripts under snodo/web/static. The tiles, pipeline, validators and execution scripts contain that placeholder call next to their real renderer registration, but protocol-savebar.js registers only its real renderer, so the assertion fails for it. The page works; the savebar tests register their own placeholder where they need one, and other tests index into the renderer list, so adding a placeholder to the savebar script would shift positions other tests rely on.

What it should do: the test keeps the script order check and checks that every one of the five scripts calls registerRenderer, which is what the shell order contract is about, instead of requiring the placeholder text. Do not change the page scripts or the renderer order.
