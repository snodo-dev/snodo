INTENT
The fixed save bar and the diff review match the mockup and use the server to preview and write the protocol file.

Evidence: in the mockup (docs/design/protocol-editor.html) a bar fixed at the bottom shows a change-count pill ("0 changes", "1 change", "n changes"), a message, and on the right the buttons Discard, Review diff and "Save to protocol.yml", all disabled while there are no changes or an empty criterion exists. Messages: "No unsaved edits.", "Unsaved edits in <validator ids>." and "A criterion is empty. Fill it or remove it before saving.". Review diff and Save both open an overlay box titled "Review changes" with a pill showing the number of changes, the sentence "A diff of .snodo/protocol.yml. Saving writes the file; committing and pushing stay with you.", the diff in a pre block (added lines in the add style, removed in the delete style, context in the muted style), and the buttons Back and "Write file". After writing, the bar message reads "Written to .snodo/protocol.yml. Commit and push when ready." Discard restores the original copy. An earlier ticket added POST preview and save routes: the preview returns the unified diff, the changes, the validity and the rule results; the save needs the page token handed out by the read route and the etag, and answers 409 when the file changed on disk and 422 when the result is invalid. The shell ticket gave protocol.js shared state with the edit list, and an empty renderer in protocol-savebar.js.

What it should do: implement the bar and the overlay with the mockup's classes, element order and copy (bar, wrap, pill aut, dim, sp, btn and pri, diff with show, box, h2, pre with the a, d and c line classes). Review diff and Save request the preview from the server and show the real unified diff of the file in the pre block (this replaces the mockup's made-up field lines; the styling stays). The Write file button saves with the token and etag, shows the refreshed data on success, and on 409 or 422 keeps the overlay closed and shows the server's message in the bar. Save and Review stay disabled while any rule is failing in the latest preview or an empty criterion exists. The page head's schema pill shows "empty criterion" in the warning style in that case, as in the mockup.
