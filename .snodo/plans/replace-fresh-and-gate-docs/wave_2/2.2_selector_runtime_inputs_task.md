## Intent
The per-task gate selects the consuming tests for the other non-Python files that shipped code reads at runtime, so a change to any of them cannot pass the gate unexamined. For the protocol templates the consumers are many, spread over several test directories, and new ones appear whenever a test is added; the selection has to find them rather than depend on a hand-kept list that someone must complete.

- Three inputs share the blind spot of the guide docs: the protocol templates under packages/snodo-foundation/src/snodo/protocols/templates (read at import time), the model benchmark prompt text file under snodo/cli/commands (consumer tests/cli/test_models_benchmark.py), and schemas/protocol-v1.json (consumer tests/scripts/test_protocol_schema_publication.py).
