What it should say: in docs/evolving-the-protocol.md, directly after the intake paragraph, a short section on proposing decision records from code: the flag, that a model (the first one in the recon model list) reads the code and proposes records for patterns it finds in at least three places with no counterexample, that each proposal lists its evidence files and is accepted or rejected one at a time, that accepted records are written with Status "Proposed" for the operator to review, that a repository with no decision records folder gets instructions for starting one and nothing is created, and that the MCP intake tool does not generate records. Link ADR 064. Keep the existing paragraphs unchanged.
