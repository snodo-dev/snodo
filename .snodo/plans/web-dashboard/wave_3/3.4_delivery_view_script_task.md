New files this task will create: `snodo/web/static/delivery.js`, `tests/web/test_static_delivery.py`.

INTENT
The Delivery view tells the person how work is landing across their projects. Add snodo/web/static/delivery.js, the script the page shell loads for #/delivery.

State of the repository before this task: the page shell snodo/web/static/index.html loads this script and calls window.snodoViews.delivery(container) on show and every 10 seconds. GET /api/delivery?days=7 (or 30) returns {"window_days", "projects": [{"name", "landed", "plans_in_main", "median_flow_seconds" or null, "first_try_rate" or null, "flow_load"}], "by_day": [{"date", "landed"}], "totals": {"landed", "flow_load", "plans_not_in_main", "median_flow_seconds" or null, "first_try_rate" or null}}.

THE CHAIN
1. snodo/web/static/delivery.js registers window.snodoViews.delivery, fetches /api/delivery with the chosen window (7d or 30d buttons, 7d by default) and renders the container.
2. It opens with one plain sentence built from the totals, for example "36 tasks landed in the last 7 days across 2 projects. A typical task takes about 6 min and 71% landed on the first try." The time and first-try parts are left out of the sentence when their value is null.
3. Below it, a row of figures: Landed, Flow time, First try, Flow load and Not in main, each showing "n/a" when the value is null. Then a bar chart of landed per day drawn with plain elements (no libraries), with the count above each bar, and a table by project with columns Project, Landed, First try and Median.
4. tests/web/test_static_delivery.py checks the file as text.

CONSTRAINTS
Build the page with DOM calls and textContent only; never innerHTML or insertAdjacentHTML. A null value is shown as "n/a", never as zero. No libraries, no external URLs. A failed fetch shows one line and keeps the last good content. Out of scope: index.html, every other script and every Python module.

ACCEPTANCE
Tests that exist and pass: the file registers window.snodoViews.delivery; it fetches "/api/delivery"; it offers both 7 and 30 day windows; it does not contain innerHTML or insertAdjacentHTML; it contains the string "n/a"; it handles a failed fetch.
