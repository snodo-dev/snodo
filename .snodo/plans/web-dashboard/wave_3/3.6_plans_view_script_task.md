New files this task will create: `snodo/web/static/plans.js`, `tests/web/test_static_plans.py`.

INTENT
The Plans view lists every plan across the projects with its progress and whether it reached the main branch. Add snodo/web/static/plans.js, the script the page shell loads for #/plans.

State of the repository before this task: the page shell snodo/web/static/index.html loads this script and calls window.snodoViews.plans(container) on show and every 10 seconds. GET /api/plans returns a list, newest first, of {"project", "name", "intent", "tasks_total", "tasks_completed", "running", "delivery" ("in_main", "not_in_main" or "no_branch"), "updated_at" (ISO time or null)}.

THE CHAIN
1. snodo/web/static/plans.js registers window.snodoViews.plans, fetches /api/plans and renders the container.
2. It renders a table with columns Plan, Project, Tasks (for example "6 / 6"), a thin progress bar, Delivery and Updated. Delivery reads "running" while running is true, and otherwise "in main", "not in main" or "no branch on record" with the not-in-main case drawn in the amber tag colour and the in-main case in green. Updated is a short date such as "Nov 14", or "n/a" when null. The plan's intent is available as a tooltip on the plan name.
3. A project filter built from the projects present (all by default) narrows the table; with a single project the filter is not shown.
4. tests/web/test_static_plans.py checks the file as text.

CONSTRAINTS
Build the page with DOM calls and textContent only; never innerHTML or insertAdjacentHTML, because plan names and intents come from files on disk. No libraries, no external URLs. An empty list shows one short line. A failed fetch shows one line and keeps the last good content. Out of scope: index.html, every other script and every Python module.

ACCEPTANCE
Tests that exist and pass: the file registers window.snodoViews.plans; it fetches "/api/plans"; it does not contain innerHTML or insertAdjacentHTML; it contains the strings "not in main" and "no branch on record"; it handles a failed fetch.
