New files this task will create: `snodo/web/static/now.js`, `tests/web/test_static_now.py`.

INTENT
The Now view shows what is running across the projects, and what is waiting for the person. Add snodo/web/static/now.js, the script the page shell loads for #/now.

State of the repository before this task: the page shell snodo/web/static/index.html loads this script and calls window.snodoViews.now(container) on show and every 10 seconds, where container is the section element for the view. GET /api/now returns {"projects": [{"name", "state" ("working" or "idle"), "plans": [{"name", "wave", "waves", "tasks": [{"task_id", "status", "job": {"job_id", "status", "elapsed_seconds"} or null}]}]}], "waiting": [{"kind": "not_in_main", "project", "plan"} or {"kind": "uncommitted", "project", "files": [...]}]}.

THE CHAIN
1. snodo/web/static/now.js registers window.snodoViews.now, fetches /api/now and renders the container.
2. It shows a row of small counts (projects with work in flight, plans in flight, tasks running, items waiting), then an "In flight" tree: each project with its state, under it each plan with "wave N of M", under it each task with its status and, when it has a job, the job id and elapsed time written like "14m". Projects that are idle are listed after the working ones with the word idle.
3. Below it, a "Waiting on you" list: a plan not in main reads "<plan>: all tasks completed, not merged into main"; an uncommitted entry reads "<n> files differ from the last commit" with the file names. When nothing is waiting it says so in one short line, and when nothing is running it says that too.
4. tests/web/test_static_now.py checks the file as text.

CONSTRAINTS
Build the page with DOM calls and textContent only; never innerHTML or insertAdjacentHTML, because plan, task and file names come from files on disk. No libraries, no external URLs. A failed fetch shows one line saying the dashboard could not be reached and keeps the last good content. Out of scope: index.html, every other script and every Python module.

ACCEPTANCE
Tests that exist and pass: the file registers window.snodoViews.now; it fetches "/api/now"; it does not contain innerHTML or insertAdjacentHTML; it contains the strings "In flight" and "Waiting on you"; it handles a failed fetch.
