INTENT
A person who has not seen the web dashboard should be able to start it and understand what it shows. Document it.

State of the repository before this task: `snodo dashboard` has the options --web/--cli (default --cli, the terminal dashboard), --port (web only) and --root (web only, repeatable; the folders are saved in web.yml in the user's snodo folder and remembered for next time). `snodo dashboard --web` serves a read-only page on 127.0.0.1 only, with four views: Now (what is running across projects and what is waiting for the person), Delivery (tasks landed, typical time, first-try rate, flow load), Gates (what the validators sent back and whether it landed) and Plans (every plan, progress, and whether it reached main). Figures the project's records cannot support show as "n/a". Projects are found by scanning the root folders for a .snodo/ directory.
