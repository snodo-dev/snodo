New files this task will create: `snodo/web/routes_gates.py`, `tests/web/test_routes_gates.py`.

INTENT
The web dashboard's Gates view answers "what did the gates send back, and did it land". Add snodo/web/routes_gates.py: a pure builder plus a Starlette handler.

State of the repository before this task: snodo/web/projects.py defines Project (attributes name and path). snodo/web/gates.py provides gate_records(project_path, window_days, now) returning records {task, plan, validator (or None), outcome ("landed_after_retry" or "not_landed"), when} and summarize_gates(records) returning sent_back, landed_after_retry and by_validator (list of {validator, count}).

THE CHAIN
1. snodo/web/routes_gates.py provides build_gates(projects, window_days, now) returning {"window_days", "sent_back", "landed_after_retry", "by_validator", "by_project", "records"}.
2. The first three come from summarize_gates over the records of all projects together. by_project lists {"name", "sent_back", "landed_after_retry"} for each project. records lists every record with a "project" field added, newest first, at most 100.
3. routes_gates.py provides async handler(request) that reads an optional days query parameter (7, 21 or 30, default 21; any other value gives status 400) and returns JSONResponse(build_gates(...)).
4. tests/web/test_routes_gates.py covers the builder with stubbed gate data and the handler with a Starlette test client.

CONSTRAINTS
Read-only and GET only. No new states; outcome labels pass through unchanged. Out of scope: snodo/dashboard/ and every file outside snodo/web/, tests/web/ and CHANGELOG.md (the one required entry).

ACCEPTANCE
Tests that exist and pass: records from two projects are merged and tagged with their project, newest first; the 100-record limit holds; by_project counts per project; by_validator is combined across projects; days=3 returns 400; the handler returns JSON with status 200.

PROCESS
Open a GitHub issue for this task first and put "Fixes #<n>" in the commit message. Add one CHANGELOG.md entry under [Unreleased] ending "(Fixes #<n>)". Before finishing, run `ruff check` on the files you wrote and fix every finding, such as unused imports.
