New files this task will create: `snodo/web/now_counters.py`, `tests/web/test_now_counters.py`.

INTENT
The local Now view shows four counts about what is running this second. The cloud Now page shows six counters that all cover the last 24 hours: Active projects, Plans / Queues, Waves, Tasks (with a per-status breakdown), Recons and Commits. Ylli wants the local page to tell the same story. This task supplies the figures: a read-only calculation, for one project, of what moved in the last 24 hours, from the files snodo already writes and from git. The route (a later task) adds the projects together.

What the figures mean, matching the cloud page: a plan counts when any of its tasks started or changed within the window; its waves count with it; Plans / Queues also reports how many distinct queues those plans belong to (from the project's queue file); Tasks counts every task of those plans plus tasks run outside any plan that moved in the window, and breaks them down by the status they report, with no status invented; Commits counts commits made in the window on any local branch; Recons counts recon runs in the window with how many are running and completed. A project is active when anything moved in the window.

Evidence for the gap: snodo/web/routes_now.py counts only projects, plans and tasks that are in progress right now.

Where a figure cannot be supported by the local files, say so explicitly (an unavailable marker the route can pass on) instead of returning zero. Recons are the likely case if no local record of them exists; check what snodo writes before deciding, and document the choice in the module docstring. Use the best timestamp the files give (job records, status files, git) and say which in the docstring; a task with no usable timestamp does not count toward the window.

CONSTRAINTS
Pure reads: no writes, no locks, no network. A missing or unreadable project directory yields unavailable figures rather than an exception. Reuse existing readers such as snodo.dashboard.providers where they already read this data. Keep the import-linter layering. Files that may change: the two new files and CHANGELOG.md; do not edit snodo/web/routes_now.py or any static file.

ACCEPTANCE
Tests that exist and pass, built on a temporary project with a real git repository and plan files: a plan touched inside the window is counted with its waves and tasks and a plan touched two days ago is not; tasks are broken down by the statuses they report; tasks outside a plan are included; commits inside the window are counted and older ones are not; an unreadable project gives unavailable figures; nothing under the project directory changes after the calculation.
