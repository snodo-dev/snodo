New files this task will create: none.

INTENT
GET /api/now still answers the old question, what is running this second, as a flat list of in-progress tasks. The Now view is changing to the cloud page's story: six counters and an In flight tree over the last 24 hours. This task makes the route return that, by assembling the two new calculations (snodo/web/now_counters.py for the figures and snodo/web/now_tree.py for the tree, both already in the repository) across every project, while keeping the Waiting on you list as it is.

Response contract, shared word for word with the view tasks that follow; null means "unavailable on this machine":
{"window_hours": 24, "generated_at": <ISO time>, "counters": {"projects_active": n, "plans": n, "queues": n|null, "waves": n, "tasks": {"count": n, "by_status": {<status>: n}}, "recons": {"count": n, "running": n, "completed": n}|null, "commits": n|null}, "projects": [{"name", "liveness": "working"|"reporting_not_progressing"|"no_recent_signal", "last_activity_at": <ISO>|null, "plans": [{"name", "wave": n, "waves": n, "last_activity_at": <ISO>|null, "wave_groups": [{"id", "total": n, "status_counts": {<status>: n}, "tasks": [{"task_id", "status", "job": {"job_id"}|null, "elapsed_seconds": n|null}]}]}], "outside_plan": [<task as above>]}], "waiting": [<unchanged: not_in_main and uncommitted entries>]}.
The counters are the per-project figures added together; a counter that is unavailable for every project stays null, and one that is unavailable for only some projects is added over the rest. Projects are ordered by last activity, most recent first.

Evidence: tests/web/test_routes_now.py and snodo/web/routes_now.py describe and build the old projects and waiting shape; every project, including idle ones, appears in the new projects list. A first attempt changed only the route and the changelog; the gate then failed because three tests in tests/web/test_routes_now.py still compare the response with the old projects and waiting shape (the unreadable-project test and the JSON handler tests among them). The route and that test file change together in this task: the gate runs the whole of tests/web, so a route change that leaves old-shape assertions behind cannot pass.
