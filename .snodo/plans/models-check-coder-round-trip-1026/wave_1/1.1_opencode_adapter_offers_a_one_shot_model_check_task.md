## Intent
`snodo models --check` needs a way to send one trivial prompt through the opencode CLI with the configured coder model and get back what the CLI did. The OpenCode CLI adapter (packages/snodo-engine/src/snodo/coders/opencode_cli_adapter.py) now has that one-shot method (`run_prompt`): it composes the adapter's own argv builder, confined environment and subprocess runner, in a directory the caller supplies, with a short bounded wait, and returns the finished run unparsed (exit code, raw stdout, raw stderr). It never reads changes back, commits, touches `.snodo` or records usage. The earlier attempts built it and judged it correct, with tests in tests/coders/test_opencode_cli_adapter.py. Do not rework the method.
