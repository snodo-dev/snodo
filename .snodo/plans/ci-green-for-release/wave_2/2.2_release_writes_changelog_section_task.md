## THE CHAIN
- In the Makefile `release` target, `scripts/enforce_changelog.py --mode release` requires entries under `[Unreleased]`. After the bump, `scripts/check_release_version.py` requires a dated section for the new version. Nothing moves the entries in between, so the v0.21.0 release had to be finished by hand. A minor or major bump leaves the table stale, which is exactly what turned CI red after v0.21.0. The release should update the table as part of the bump, before the release commit.
