# Tunnel client secrets are printed to the terminal

First open a GitHub issue for this work. Write the body to a file under /tmp and pass it with `gh issue create --body-file`, never as an inline string. The commit message must say "Fixes #<that issue number>". Add a CHANGELOG entry under ## [Unreleased].

## INTENT
Snodo never prints a credential (client secret, service-token secret, tunnel token) to stdout or stderr. The user is told where the secret was stored and how to retrieve it on purpose, so secrets don't end up in scrollback, CI logs or screen captures.
