# A job cancel can be overwritten by the wrapper's final status

First open a GitHub issue for this work. Write the body to a file under /tmp and pass it with `gh issue create --body-file`, never as an inline string. The commit message must say "Fixes #<that issue number>". Add a CHANGELOG entry under ## [Unreleased].

## INTENT
Once a job is cancelled it stays cancelled. Concurrent status writers (cancel, the wrapper's final write, the reconcile and archive paths) never lose each other's terminal status or exit code.

## THE CHAIN
- Recon rec_30f4e0: `cancel` in `packages/snodo-mcp/src/snodo/jobs/__init__.py` (around lines 646–648) reads the state, sends SIGTERM and writes `cancelled`.
- The wrapper (`packages/snodo-mcp/src/snodo/jobs/wrapper.py`, around lines 134 and 142–149) re-reads the state and overwrites it with `completed` or `failed` unless its own copy already said `cancelled`.
- `_reconcile_state` (around lines 199–270) and `archive_jobs` (around lines 687–692) are also unlocked read-modify-writes through `atomic_write_json`.
- An earlier wave made `task.json` writes atomic in the same module; build on that.

## CONSTRAINTS
- Serialise job `state.json` read-modify-writes with the existing locked update helper.
- The wrapper's final write must not replace a terminal status that is already recorded (`cancelled`, or one set by reconcile).
- No new status, severity, halt type or audit event.
- Never pass text containing backticks or `$(` through an inline shell string. Commit messages and issue bodies go through files under /tmp.
- Do not run the `snodo` CLI, `make release` or `make gate` in the worktree, and do not create, change or delete anything under `.snodo/` in the repo. Tests use temporary job directories.
- Run `uv run ruff check` and `uv run python scripts/enforce_file_length.py` on touched files. Run only the targeted job and wrapper tests.

## ACCEPTANCE
- A test cancels a job, then runs the wrapper's final write; the state stays `cancelled`.
- A test shows reconcile and the wrapper don't lose each other's exit code.
