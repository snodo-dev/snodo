INTENT
On the Now page each task in the In flight tree is a row that does nothing when clicked. Ylli wants a panel on the right side that opens for the task he clicked, as the snodo-cloud task detail panel does. This task builds the panel itself and wires the rows to it; the spec text inside the panel comes from a later task, so for now the panel body says that the spec is loading.

Evidence: snodo/web/static/now.js draws task rows (task id, status mark, status word, elapsed time) as plain rows without any click behaviour, and the page has no side area.

What the person should see: a task row, in a plan or in the Outside a plan group, is a button; clicking it opens a panel docked to the right edge, beside the tree, on wide screens, and full-width over the page on narrow ones. The panel header shows the task id in monospace, its status as received, the plan and wave it belongs to (or "Outside a plan"), the job id and the elapsed time when there is one, and a close button. Escape and the close button close it; clicking another task switches the panel to that task; the row of the open task is marked as selected. The panel stays open and keeps its task across the 10-second refresh, updating the status and elapsed time if they changed, and closes itself when the task is no longer in the data. Focus moves into the panel when it opens and back to the row when it closes; the panel is a labelled complementary region and the row buttons carry aria-expanded or aria-pressed for the selected state.
