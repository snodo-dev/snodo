# 1.3_machine_interface_compare_json

## INTENT
`docs/machine-interface.md` documents the JSON of `snodo models --benchmark --json` (schema `snodo.models-benchmark.v1`) but not the JSON of the task comparison, which `snodo models --compare --json` and `snodo models --benchmark-run --json` emit through `snodo/cli/commands/plan_compare.py`. A script that wants to rank candidate models has to read the source to learn the shape. Evidence: the user guide says "`--json` emits the comparison data as JSON" and stops there.

## THE CHAIN
1. Open a GitHub issue first ("Machine interface does not document the task comparison JSON") and put "Fixes #<n>" in the commit message.
2. Read `snodo/cli/commands/plan_compare.py` (the structure it builds for `--json`, including the schema name, `direction`, `delta_score`, `signals`, run metrics and the candidate status fields) and `models_benchmark.py` (what `--benchmark-run --json` adds). Run the existing tests for the comparison to see real output where a test prints or asserts it. Every field you document must be seen in the code; do not invent fields or examples.
3. Add a section to `docs/machine-interface.md` next to the `snodo models --benchmark --json` section, in the same table style (field, type, meaning), with the schema name, every top-level field, the shape of `signals`, the run-metrics block, how a missing value is represented, and which fields are scored versus shown only.
4. `CHANGELOG.md` gets one new line under `[Unreleased]` in the same commit, in the style of the neighbouring entries, ending with "(Fixes #<n>)".
5. Run the docs checks the gate runs for `docs/`; fix what they report in your own change only.

## CONSTRAINTS
- Only `docs/machine-interface.md` and `CHANGELOG.md` may change. No code, no test file.

## ACCEPTANCE
- `docs/machine-interface.md` has a new section for the task comparison JSON that names its schema and lists its fields in the table style of the neighbouring sections.
- The diff adds one line under `[Unreleased]` in CHANGELOG.md that mentions the issue.
- No file other than the two named differs.
